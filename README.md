# Techno Installer

A user-installable (non-privileged) port of the Android 4.3 AOSP `PackageInstaller` system app.

- Original package: `com.android.packageinstaller` (system, signature|privileged)
- New package: **`com.techno.installer`**
**REQUIRES GRADLE AND ANDROID STUDIO TO COMPILE!**
  
## Seamless install/uninstall via Shizuku & Bypass SDK Block

This build integrates Shizuku and the `bypass sdk block` command. It is not tested yet.
